# README captures

`overview-demo.png` and `sensors-demo.png` show the unmodified application frontend
of Argus 0.2.0, served with `node tools/serve-ui.mjs` at
`http://127.0.0.1:4173`. Captured on 2026-10-13 with the T3 browser snapshot tool
at a 1440 × 900 viewport; the saved PNGs are 1280 × 800. The dark theme,
demonstration banner and synthetic backend remain visible.

The native 0.2.0 app was also opened and captured during verification. Its header
includes this machine's name, so public captures use the demo. No native values
were inserted into the demo and no demonstration labels were removed.

To refresh the images, start the server, wait for the chart to fill, open Overview
and Sensors, and capture each view at the same size. Keep the synthetic-data
captions in the main README. Check for machine names, addresses, serial numbers
and personal paths before committing native captures.
